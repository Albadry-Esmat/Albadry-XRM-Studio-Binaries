# Albadry XRM Studio Binaries

Public distribution metadata and GitHub Release assets for Albadry XRM Studio.

Release binaries are attached to GitHub Releases rather than committed to this
repository. Each release has a versioned manifest under `releases/` that binds
the exact source commit, archive names, byte sizes, SHA-256 checksums, and
known trust limitations.

The latest Alpha candidate may be prepared as a **draft prerelease** before it
is made public. Check the release status and platform notes before downloading:
macOS packages may be replaced independently of Windows and Linux packages.
Alpha packages are experimental and must not be used with production Dataverse
data or for business-critical work.
